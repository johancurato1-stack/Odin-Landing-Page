# Odin Landing Page

A responsive landing page built using **HTML and CSS** as part of [The Odin Project](https://www.theodinproject.com/) Foundations curriculum.

The project focuses on recreating a provided landing page design while applying fundamental CSS concepts, Flexbox layouts, responsive web design, and accessibility practices.

## Live Preview

[View Live Website](https://johancurato1-stack.github.io/Odin-Landing-Page/)

## Features

- **Responsive Layout** – Adapts to desktop, tablet, and mobile screen sizes.
- **Flexbox Layouts** – Uses CSS Flexbox to organize and align page elements.
- **Semantic HTML** – Uses appropriate HTML elements to structure the webpage.
- **Accessibility Improvements** – Includes accessible navigation, keyboard accessibility, and screen-reader-friendly content.
- **Consistent Styling** – Follows the original Odin Project reference design, including its colors, typography, and layout.

## Design Reference

This project follows the official [Odin Project Landing Page](https://www.theodinproject.com/lessons/foundations-landing-page) assignment.

The original design was recreated using HTML and CSS, with additional responsive and accessibility improvements.

## Validation and Testing

- HTML validated using the [W3C Nu HTML Checker](https://validator.w3.org/).
- CSS validated using the [W3C CSS Validation Service](https://jigsaw.w3.org/css-validator/).
- Responsive layout tested using Chrome DevTools.
- Keyboard navigation and visual readability checked.

Both HTML and CSS validation completed with **zero errors and zero warnings**.
